# Trailhead Co. Sizing Guide

Trail Runner 2 and Trail Runner 3 share a last. Shoppers should choose the same size in both models.

For the trail shoes, recommend the shopper's normal running shoe size. If they are between sizes or expect foot swelling during an ultra, suggest the larger half size.

Ridge Lite runs true to size. The Race Vest should fit snugly without restricting breathing; if between sizes, size up.
