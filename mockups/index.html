1 · Storefront — pet closed

The Trailhead Co. product page a shopper lands on. The Shopkeeper sits bottom-right as a small app icon: idle, breathing, with a status badge. It never advertises that prices are negotiable.

2 · Storefront — pet open, Find

Click the pet and it expands into a chat panel over the page. It already knows which product you are on and who you are (cookie id + one seeded memory).

3 · Storefront — Deal, then Close

The haggle mid-flow. A lowball gets the offended face and a trade, never a free discount. The offer card renders instantly from the engine; the text streams in after.

4 · The pet — state sheet

One character, five reaction states, keyed off ChatEvent.mood. A warm, witty bazaar shopkeeper: cream face, terracotta fez with a forest-green tassel, proper moustache, on a marigold app-icon tile.

idle

mood: "idle"

Trigger: default. Panel closed or open with no turn in flight; also after settled cools down or an offer expires.
Reads as: attentive, soft smile.

thinking

mood: "thinking"

Trigger: POST /chat received; held while parse → engine → phrase runs, cleared by the first text delta.
Reads as: eyes up, one brow raised, thought dots.

offended

mood: "offended"

Trigger: engine decision on an offer that is a lowball (well under ask(r) / under floor), or any blocked attempt.
Reads as: wide eyes, V brows, fez knocked askew.

tempted

mood: "tempted"

Trigger: an offer within striking distance, so the ladder returns BUNDLE, TIMER or STEER; also the hesitation nudge.
Reads as: side-eye, raised brow, smirk, coin glint.

deal

mood: "deal"

Trigger: settled event — Auditor passed, code minted, total matches.
Reads as: happy closed eyes, big grin, sparkles, green check.

How to rebuild it

  • Fixed layers (never change): tile, shoulders, face, cheeks, nose, moustache.
  • Swapped layers (4 per state): eyes, brows, mouth, accessory. The fez only changes its rotation (0°, 0°, −14°, 0°, +8°).
  • 5 sprites (30-minute path): each state in this file is one inline SVG on a 120×120 viewBox — copy it from the DOM, save as pet-idle.svg etc., swap src on mood, cross-fade 120 ms.
  • Rive path: one artboard, one state machine, one number input mood 0–4; idle gets the bob + blink loop, the other four are 200 ms one-shot poses that hold. If using the community mascot as-is, map its six expressions onto these five names.
  • Character is a design asset, not the pitch. Do not lead with it.
